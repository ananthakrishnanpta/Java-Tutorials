## How to study this part

1. Read for the mental model, not for memorization.
2. Type and run the examples yourself with `javac` and `java`.
3. Change one input or assumption at a time and explain the result.
4. Solve the exercises without looking at a solution first.

**Done means:** you can explain the topic in plain language, write a small program using it, and identify one trade-off or pitfall.
