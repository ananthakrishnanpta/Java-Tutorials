# Java Tutorials — Basics to Expert

A practical learning path for Core Java, JVM internals, data structures, algorithms, concurrency, and interview preparation.

## Start here

Install a JDK (JDK 21 or newer is recommended), then confirm both commands work:

```bash
java --version
javac --version
```

Read each lesson in order, type the example yourself, change one thing, and explain the result. A directory may be an authoring space for future examples or exercises; a lesson never requires a file that is not present.

## Repository conventions

- `examples/` contains focused runnable programs when a lesson needs one.
- `exercises/` is for learner challenges; work independently before comparing approaches.
- `diagrams/` and `internals/` support runtime and implementation explanations.
- The problem-solving track groups problems by technique and difficulty.
